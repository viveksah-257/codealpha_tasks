# Task 1 - Hangman Game

## Description

This project is a simple text-based Hangman game developed using Python.

The player has to guess a randomly selected word one letter at a time.

## Features

- Uses 5 predefined words
- Randomly selects a word
- Allows the user to guess one letter at a time
- Allows a maximum of 6 incorrect guesses
- Displays the progress of the guessed word
- Prevents repeated guesses

## Concepts Used

- Python lists
- Strings
- Random module
- while loop
- if-else statements
- for loop
- User input and output

## How to Run

Run the following command:

```bash
python hangman.py
