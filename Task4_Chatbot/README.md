# Task 4 - Basic Chatbot

## Description

This project is a simple rule-based chatbot developed using Python.

The chatbot responds to specific predefined user inputs.

## Supported Inputs

- hello
- how are you
- bye

## Features

- Takes input from the user
- Provides predefined responses
- Uses a function to process user input
- Continues chatting until the user types "bye"

## Concepts Used

- Functions
- if-elif-else statements
- while loop
- Strings
- User input and output

## How to Run

Run the following command:

```bash
python chatbot.py
